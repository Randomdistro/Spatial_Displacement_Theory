# Quick Start: Coordinating Development

## The Four Agents

- 🎨 **Creative Agent (Me)**: Beautiful things, geometry, style. Subtle, subdued, visceral.
- 🐒 **Codemonkey Agent**: Framework expert. Powerful, convenient, demanding, easy.
- ⚙️ **Simulations Expert**: Physics simulations like puzzle games. Clockwork precision.
- 🔧 **Integration Agent**: Tests, breaks things, reports. ONLY agent allowed to use stubs/placeholders.

## TL;DR - How to Work With Me

Since I'm a single AI assistant (not four separate agents), here's the simplest way to coordinate:

### Option 1: Just Tell Me What You Want
```
"Create the Flower of Life landing page"
"Write the content for Path 1, Node 1"
"Build the pressure field simulation"
"Set up the navigation system"
```

I'll figure out which "agent role" is needed and do the work.

### Option 2: Explicit Role Assignment
```
"Act as Agent 1 and create the 3D Flower of Life component"
"Switch to Agent 2 and write the first node content"
"Agent 3, build the orbital simulation"
"Agent 4, wire up the routing"
```

### Option 3: Phase-Based
```
"Let's start Phase 1 - set up the foundation"
"Now do Phase 2 - build the Flower of Life"
"Continue with Phase 3 - create the content"
```

## Recommended Workflow

1. **Start a session**: Tell me what you want to work on
2. **I work**: I'll create/update files and document progress
3. **You test**: Test what I built
4. **Iterate**: Tell me what to fix or what's next

## Tips

1. **Be specific**: "Create the Flower of Life" is better than "do the 3D stuff"
2. **Test incrementally**: Test after each major component
3. **Check status**: Look at `agent-coordination.md` to see progress
4. **Ask questions**: "What's the next step?" or "What do we need to do next?"
