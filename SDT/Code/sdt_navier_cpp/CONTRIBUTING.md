# Contributing to SDT-Navier C++ Simulator

Thank you for your interest in contributing to the SDT-Navier project!

## Development Setup

1. Fork the repository
2. Clone your fork
3. Create a development branch
4. Set up the build environment (see BUILD.md)

## Code Style

- Follow C++20 best practices
- Use meaningful variable and function names
- Add Doxygen comments for public APIs
- Keep functions focused and small
- Use `const` where appropriate
- Prefer `constexpr` for compile-time constants

## Testing

- Add unit tests for new functionality
- Ensure all tests pass: `ctest`
- Maintain or improve test coverage

## Documentation

- Update API.md for new public APIs
- Update README.md for user-facing changes
- Add examples for new features
- Update CHANGELOG.md with significant changes

## Pull Request Process

1. Ensure code compiles and tests pass
2. Update documentation as needed
3. Create a clear PR description
4. Reference any related issues

## Areas for Contribution

- Performance optimizations (SIMD, parallelization)
- Additional nuclear system models
- Enhanced I/O capabilities (HDF5, VTK)
- GPU acceleration (CUDA/OpenCL)
- Improved numerical methods
- Extended test coverage
- Documentation improvements

## Questions?

Please open an issue for questions or discussion.
