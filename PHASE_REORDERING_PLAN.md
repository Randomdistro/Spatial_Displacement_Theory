## Overview

This document outlines the plan to reorder all SDT phases into a logical, sequential numbering system based on:
1. **Dependencies** - Phases that build on others must come later
2. **Scale** - Atomic → Molecular → Macroscopic → Cosmological
3. **Topic Grouping** - Related phases grouped together
4. **Progression** - From foundational principles to advanced applications
