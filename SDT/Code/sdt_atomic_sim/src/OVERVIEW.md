# sdt_atomic_sim/src — Overview

Implementation source files for the atomic simulation module.

## Subfolders

- **physics/** — 🔴 Electron orbital QM implementations: radial wave functions (Laguerre), spherical harmonics, probability density grids, oscillator strengths, Einstein A coefficients
- **simulation/** — Atomic engine: electron adding, total energy calculation
- **io/** — Atomic data loader implementation
- **visualization/** — Orbital viewer: 3D rendering of probability density grids
