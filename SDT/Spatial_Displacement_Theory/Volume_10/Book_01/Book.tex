\chapter{Molecular Structures as Flux Topology}

\section*{Abstract}
This book provides the narrative frame for the molecular compendium volumes. Each molecule is a
configuration of boundary geometry stabilized by flux meshing. The compendium is therefore an atlas of
occlusion patterns rather than a catalog of unrelated compounds.

\section{Structure as Geometry}
Molecular structure is a multi-boundary arrangement that maximizes stable shared flux while minimizing
occlusion conflict. The guiding principle is geometric compatibility across nuclei.

\section{Compendium Cross-Reference}
All molecule-by-molecule analyses reside in the Molecular Structures volumes. This book defines the
interpretive frame by which those volumes are read.

\chapter{Classification of Molecular Topology}

\section*{Abstract}
Molecular topology is classified by boundary count, wake mesh count, and occlusion symmetry. This chapter
provides the classification rules used in the atlas.

\section{Topology Classes}
\begin{equation}
\mathcal{T} = (N_b, N_w, \sigma_E),
\end{equation}
where $N_b$ is boundary count, $N_w$ is wake mesh count, and $\sigma_E$ is occlusion symmetry.

\chapter{Reading the Atlas}

\section*{Abstract}
The atlas is structured to emphasize geometry before chemistry. This chapter explains how entries are
organized and how to interpret the geometric fields.

\section{Entry Structure}
Each entry defines boundary geometry, wake alignment, occlusion map, and stability notes.

\chapter{Bridge to Atomic Canon}

\section*{Abstract}
Molecular structures are built from atomic boundary units. The atomic canon provides the elemental
geometries that seed the molecular atlas.

\section{Canonical Link}
Atomic geometry data are referenced from \texttt{SDT/ATOMICUS}. Molecular entries inherit those
geometries and compute shared flux arrangements.
