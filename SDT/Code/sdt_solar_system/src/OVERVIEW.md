# sdt_solar_system/src — Overview

Implementations for the SDT solar system simulation.

## Files

- **camera_controller.cpp** — ✅ Camera controller for 3D viewport navigation
- **jpl_de421_loader.cpp** — ✅ JPL DE421 ephemeris data loader: parses binary ephemeris for planet positions
- **point_particle_system.cpp** — ✅ Point particle N-body system: pressure-field force integration
