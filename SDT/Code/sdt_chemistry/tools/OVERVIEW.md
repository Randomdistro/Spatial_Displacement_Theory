# sdt_chemistry/tools — Overview

CLI tools for the SDT molecular chemistry engine.

## Files

- **compound_designer.cpp** — ✅ Interactive compound designer: build molecules by specifying atoms and bonds
- **molecule_viewer.cpp** — ✅ Molecule viewer: load and visualise molecular structures
- **batch_processor.cpp** — ✅ Batch processing: compute properties for multiple molecules from a list
