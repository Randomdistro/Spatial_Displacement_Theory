# sdt_solar_system/tools — Overview

Standalone executables for solar system simulation and analysis.

## Files

- **solar_system_sim.cpp** — ✅ Main solar system simulator: N-body integration with SDT pressure-field dynamics
- **analysis_tool.cpp** — ✅ Orbital analysis: period, eccentricity, energy conservation checks
- **trajectory_viewer.cpp** — ✅ Trajectory visualisation: output orbital paths
- **vulkan_solar_system_viewer.cpp** — ✅ Full Vulkan 3D solar system viewer with real-time rendering
- **vulkan_solar_system_viewer_simple.cpp** — ✅ Simplified Vulkan viewer for quick visualisation
