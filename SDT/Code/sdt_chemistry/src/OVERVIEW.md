# sdt_chemistry/src — Overview

Implementations for the SDT molecular chemistry engine.

## Files

- **bonds.cpp** — ✅ Bond type implementations and pressure-field bond strength calculations
- **elements.cpp** — ✅ Full periodic table element data (Z=1–118): orbital configurations, nuclear geometry references
- **molecules.cpp** — ✅ Molecular assembly: atom placement, bond formation, geometry optimisation
- **geometry.cpp** — ✅ Geometry calculations: distance, angles, dihedrals
- **properties.cpp** — ✅ Property computations: dipole, polarisability, ionisation energy
- **designer.cpp** — ✅ Molecular designer implementation
- **data_loader.cpp** — ✅ Data loader for reference datasets
- **visualizer.cpp** — ✅ Visualisation renderer: ball-and-stick, pressure field overlay, output formats
