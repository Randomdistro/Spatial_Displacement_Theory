## Validation Report Format

Each benchmark produces a JSON validation report:

```
SDT/benchmarks/B##_validation_report.json
```

Standard fields:
- `benchmark_id`: B01-B100
- `status`: CERTIFIED | UNDER_INVESTIGATION | DRAFT
- `domain`: Physics domain
- `sdt_derivation`: Postulates used, geometric argument, equations
- `comparison`: Experimental vs SDT vs standard physics
- `relative_error`: Percentage deviation
- `distinguishing_features`: Where SDT differs from standard physics
