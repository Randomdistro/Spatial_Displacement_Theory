# sdt_redshift — Overview

Python SDT redshift calculator. Implements redshift as a pressure-gradient displacement effect in the spation medium — no expanding universe, no Doppler interpretation.

## Files

- **__init__.py** — Package initialisation
- **calculator.py** — ✅ SDT redshift calculation from pressure-gradient displacement
- **sd_redshift.py** — ✅ Simplified redshift utility
- **sdt_redshift.md** — Documentation of the SDT redshift model and derivation
- **test_redshift.py** — ✅ Tests for redshift calculations against observed data
